# Стройка уровней GD через мост

Мод `claude.bridge` (папка `mod/`, спецификация `mod/SPEC.md`) слушает 127.0.0.1:47800. Всё
делается командами — скриншоты не нужны (если нужен взгляд — `tools/ui.ps1 shot <png> 0.35`).

## Перед работой
1. Игра запущена с модом: `python -P tools/bridge.py ping` -> `{"scene": ...}`. Нет ответа —
   `powershell -File tools/gd_restart.ps1` (запускает exe напрямую, НЕ через Steam).
2. Уровни пользователя не трогать без его слова. Новый уровень — своё имя (`editor_open` создаст).

## Python API (`tools/gdedit.py`, `tools/gdobjects.py`)
```python
import sys; sys.path.insert(0, r'D:\GDRetina\tools')
from gdedit import Editor
from gdobjects import obj, block, spike, portal, trig_move, trig_color, trig_alpha, trig_toggle, ID, KEYS
ed = Editor()
ed.open('NAME', song_id=1029814)          # открыть/создать уровень в редакторе
ed.settings(start_mode=0, start_speed=1)  # стартовый режим 0 куб..7 swing, скорость 0.5..4, song_offset...
uids = ed.add([block(15, 15), spike(45), portal('ship', 300), portal(2, 300), obj(36, 400, 75)],
              label='intro')              # label виден в истории и в интерфейсе
ed.list(x0=0, x1=600, full=True)          # объекты со всеми свойствами (props = строка как в сохранении)
ed.modify(uids=uids[:2], set={'rot': 90, 'groups': [3]}, dy=30)
ed.remove(x0=500, x1=900)                 # фильтры: uids ids x0 x1 y0 y1 groups selected all
ed.undo()                                  # откат последнего действия ИИ (add/remove/modify)
ed.select(ids=[8]); ed.selected()          # выделить (видно человеку) / что выделил человек
ed.view(x=600, y=90, zoom=0.7)            # показать место камерой
ed.save(); ed.exit()
```
CLI: `python -P tools/gdedit.py <команда> '<json>'` (например `add '{"objects": "1,1,2,15,3,15"}'`).
Все команды моста: `python -P tools/bridge.py commands`.

## Объекты и свойства
- Объект = строка «ключ,значение,…» как в сохранении: `1` ID, `2` x, `3` y, `6` поворот, `4/5`
  отражение, `128/129` масштаб, `57` группы (`3.7`), `21/22` цвета, `24/25` слой/порядок…
  Имена ключей — `gdobjects.KEYS`; любой ключ можно передать как `k<номер>=…`.
- Координаты: x вправо, блок 30 ед. (центры на 15+30k); y от земли (блок на земле y=15).
- Справочник ВСЕХ 4092 объектов игры (класс solid/hazard/slope/special/decor, хитбокс, свойства по
  умолчанию): `data/gd_objects.json`, поиск `python -P tools/gdfind.py <слово>` /
  `--class hazard` / `--triggers` / `--id 901`.
- Неизвестно, какой ключ за что отвечает у триггера? Варианты: `object_probe` (свойства по
  умолчанию), либо попросить пользователя поставить и настроить пример в редакторе, выделить его
  и прочитать `ed.selected()` — это точный способ выучить любой объект.
- Ограничения игры: твёрдые блоки поворачиваются только на 90° (иначе поворот отбрасывается);
  наклоны — склоны (289 45°, 291 22.5°), шипы/декор поворачиваются свободно. Игра ищет
  столкновения в секциях по 100 ед. по центру объекта — твёрдые блоки шире ~60 ед. резать на
  куски. Порталы срабатывают при касании хитбоксов (см. `gdobjects.PORTAL_HW`); все порталы одной
  точки ставить в один x, момент касания задавать шириной (`gen_layout.portal_x`).

## Чужие уровни (референсы)
`ed.levels('saved')` — скачанные онлайн-уровни; `ed.export(id=...)` / `ed.export()` (текущий:
открытый уровень, редактор или страница уровня) -> сжатая строка; распаковка —
`tools/gdsave.decode_level_string`. Разбор — `tools/analyze_level.py`, `tools/render_map.py`.
Перед анализом — спросить пользователя, какие уровни брать, или предложить свои варианты.
Чужие уровни — источник приёмов и статистики, не копировать куски в свой уровень.

## Интерфейс в игре (заявка, статус, сообщения)
- Игрок может оформить заявку в игре: меню Create -> «Claude AI» или кнопка «AI» в редакторе ->
  «New Level» (имя, Song ID, файл песни, сложность, упор для Hard/Insane/Extreme Demon, заметки).
  Фраза в чате вроде «бери заявку из GD» -> `ed.request()`; поле `focus_asked=false` значит, что
  упор не спрашивался (ниже Hard Demon) — по умолчанию «красота».
- Во время работы держать игрока в курсе: `ed.request_status('building', 'раздел 3/12')`,
  `ed.status('строю раздел 3: волна', 0.25)`, в конце `ed.request_status('done')`,
  `ed.notify('Level ready!', 'success')`. Русский текст игра покажет транслитом (шрифты GD без
  кириллицы), короткие английские фразы читаются лучше.
- Песня-файл из заявки (`song_file`): скопировать mp3 поверх `%LOCALAPPDATA%\GeometryDash\<song_id>.mp3`
  (сначала сохранить оригинал рядом с суффиксом `.orig`), в уровне — этот song_id.
- Настройки мода (игрок): AI Server, Port, Read-only (мост отвечает ошибкой на любые правки — не
  обходить, сказать пользователю), Backup before AI edits (копии в
  `%LOCALAPPDATA%\GeometryDash\geode\mods\claude.bridge\backups`), уведомления, кнопка AI.
- Референсы из заявки: `references` — список `{id, name, creator, downloaded}` (отмеченные игроком
  скачанные уровни) и/или `{text}` (вписанные названия). Пусто — выбрать самому из скачанных.
- Автозапуск: при включённой настройке «Start Claude on Send» кнопка Send запускает
  `tools/start_claude.py` -> Claude Code в АВТОРЕЖИМЕ (текст задания `tools/auto_prompt.md`): без
  чата и вопросов, разрешены только чтение/правка файлов проекта и `python -P tools/...`,
  `python -P out/auto/...`. Лог — `out/claude_runs/`. Игрок видит «Claude run: running 01:23», кнопка
  «Stop AI» убивает прогон. Из чата: `run_start` / `run_stop` / `run_status`.
- Проверить интерфейс без скриншота: `bridge.py ui_nodes '{"id": "claude.bridge/claude-button"}'`;
  если нужен взгляд — `tools/winshot.ps1 <png> 0.45` (снимок окна GD без фокуса и нажатий).
  Не нажимать клавиши и не перехватывать фокус окна, пока пользователь работает за компьютером
  (клавиша уйдёт в его окно).

## Стройка уровня ИИ — «сначала путь» (с 19.10)
- Руководство: `docs/design_guide.md` (правила по прошлым ошибкам, физика с числами, цели сложности, §5).
- Музыка: `python -P tools/music_map.py <song_id> [--detail T0 T1]` (темп, разделы, сильнейшие удары).
- Код уровня — `out/auto/level.py` на `tools/lvlkit.py` + `tools/lvlpath.py`: смены `L.change(t, ...)`;
  путь игрока `P = L.path()` — `P.click/hold/orb/pad` на ударах; траектория `P.at(t)` (модель сверена с
  игрой тик в тик: `tools/cal_path.py`, `tools/cal_jump.py`); препятствия вокруг неё (`L.corridor`,
  `L.wave_corridor`, свои); `L.check()`; `L.save()`. Пример — `tools/lvlkit_example.py`.
- В редактор: `python -P tools/lvl_build.py out/auto/level.py` (частями, с подписями, сохранить, выйти).
- Проверка: `python -P tools/lvl_check.py "<имя>" --difficulty "Insane Demon"` — бот: ОДИН прогон нажатий
  пути в игре (мод sim_*, 4 шага на кадр) + разбор `out/levels/<имя>/review.md` + картинки.
- Старое: `tools/compose.py` (генератор) и `tools/solver.py` (бот-перебор) — не для стройки уровней ИИ.

## Быстрый путь: целый уровень одной командой
`python -P tools/compose.py --name "ИМЯ" --song-id ID [--bpm N] --difficulty "Hard Demon" --focus Balanced --editor --verify`
(или `--request bridge` — заявка из игры). План можно выгрузить (`--plan-out`), доработать и подать
(`--plan-in`) — см. `docs/design_guide.md` §6. Результат: `out/compose/<имя>/` (level.gdlvl, inputs,
plan, verify). Руководство по дизайну — `docs/design_guide.md`, профили референсов — `data/refs/`.

## Порядок работы по промпту
1. Уточнить: имя уровня, песня (ID или файл), сложность. Для Hard/Insane/Extreme Demon спросить
   упор: сложность / красота / середина; ниже — по умолчанию красота. (Или взять заявку из игры.)
2. Музыка -> сетка и разделы (`tools/timing.py`, `tools/audio_*.py`).
3. План разделов: режим, скорость, характер, приёмы — разнообразно (не повторять соседний приём,
   контраст по энергии трека, переходы — тоже геймплей).
4. Стройка по разделам через `ed.add(..., label='раздел N: …')`, показывать камерой.
5. Проверка: `ed.save(); ed.exit()`, затем `tools/lvl_check.py` (один прогон пути + разбор).
   Физика зависит от разбиения шагов по кадрам: бот моста идёт с фиксированными 4 шагами на кадр
   (60 FPS) — прогоны воспроизводимы тик в тик.
6. Отчёт пользователю: что построено, что проверено, что нет.
