# Claude Bridge — ИИ строит уровни Geometry Dash

Мод для Geometry Dash (Geode) + набор инструментов на Python: заполняешь заявку прямо в игре
(название, песня, сложность, упор, модель Claude), жмёшь **Send to Claude** — Claude Code сам
придумывает и строит уровень в редакторе под музыку, а бот проверяет, что уровень проходим.

*English: a Geode mod + Python tools. Fill a request inside Geometry Dash, press "Send to Claude", and
Claude Code designs and builds a music-synced level in the editor; a bot then verifies it is beatable.
Requires GD 2.2081, Geode 5.11.2, Python 3.11+, Claude Code CLI with a Claude subscription.*

> Версия **1.4.0** (октябрь 2026). Проект в разработке: проходимость уровней проверяется, а качество и
> разнообразие геймплея ещё улучшаются.

---

## Что умеет

- **Окно заявки в игре:** название, ID песни (или свой файл), сложность, упор (сложность / баланс /
  красота — для демонов), заметки, уровни-референсы, выбор модели (Sonnet 5.5 / Opus 5.5) и глубины
  размышлений (Low…Max).
- **Автозапуск:** по Send мод запускает Claude Code в фоне — без чата. Ход работы виден в панели
  «Claude Bridge» (статусы, последние действия), кнопка **Stop AI** останавливает.
- **Стройка в редакторе:** уровень появляется в редакторе частями с подписями; перед первой правкой ИИ
  делается бэкап.
- **«Сначала путь»:** ИИ задаёт путь игрока (нажатия на удары музыки), точная модель физики GD считает
  траекторию, препятствия ставятся вокруг неё; модель сверена с игрой тик в тик (куб, корабль, НЛО,
  волна, шар, паук, смены скорости и гравитации, орбы, пады).
- **Бот:** проходит уровень одним прогоном нажатий пути прямо в игре и даёт разбор: прошёл ли,
  окна таймингов, частота смен режима, синхронность с музыкой, картинки участков.
- **Мост для разработчиков:** TCP 127.0.0.1:47800 — команды редактора, запуск уровней, бот
  (см. `mod/SPEC.md`).

## Требования

| Что | Версия |
|---|---|
| Windows | 10 / 11 |
| Geometry Dash (Steam) | **2.2081** — мод собран под неё |
| Geode | **5.11.2** |
| Python | 3.11 или новее, в PATH (команда `python`) |
| Пакеты Python | numpy, scipy, soundfile, Pillow (`requirements.txt`) |
| Claude Code CLI | установлен и выполнен вход (нужна подписка Claude Pro/Max) |

> Каждая стройка тратит лимит твоей подписки Claude. Opus с глубокими размышлениями — медленнее и
> дороже; для пробы бери Sonnet 5.5 + High.

## Установка

1. **Geode.** Установи Geode 5.11.2 для Geometry Dash 2.2081 (установщик — geode-sdk.org).
   Запусти игру и убедись, что в главном меню появилась кнопка Geode.
   *Если Steam обновил игру до версии, которую Geode ещё не поддерживает, мод не загрузится.*
2. **Мод.** Скопируй `release/claude.bridge.geode` в папку модов игры:
   `...\steamapps\common\Geometry Dash\geode\mods\`.
3. **Папка проекта.** Распакуй архив, например в `C:\ClaudeBridge` (путь без кириллицы и пробелов —
   надёжнее). В ней должны лежать `tools\`, `data\`, `docs\`.
4. **Python-пакеты.** В папке проекта:
   ```
   python -m pip install -r requirements.txt
   ```
5. **Claude Code CLI.** Установи (например `npm install -g @anthropic-ai/claude-code`, нужен Node.js
   18+, или официальный установщик), затем один раз запусти `claude` в терминале и войди в аккаунт.
6. **Настройки мода в игре.** Главное меню → Geode → установленные моды → **Claude Bridge** →
   настройки (шестерёнка):
   - **Project folder** — путь к папке проекта, например `C:\ClaudeBridge`;
   - **Start command** — `python -P "C:\ClaudeBridge\tools\start_claude.py"` (тот же путь);
   - остальное можно оставить: AI Server — вкл., Port — 47800, Start Claude on Send — вкл.
7. **Перезапусти игру.**

Проверка (необязательно): при запущенной игре в папке проекта
```
python -P tools/bridge.py ping
```
должен ответить версией мода.

## Как пользоваться

1. Главное меню → **Create** (молоток) → кнопка **Claude AI** (внизу справа). В редакторе есть кнопка
   **AI**.
2. В панели «Claude Bridge» нажми **New Level**.
3. Заполни заявку:
   - **Name** — новое имя уровня (уровни с таким же именем, сделанные не ИИ, мод не трогает);
   - **Song ID** — ID песни Newgrounds; песня должна быть **скачана в игре** (или укажи файл);
   - **Difficulty** и **Focus**;
   - **Notes**, **References** — по желанию;
   - кнопка **Claude** — модель и глубина размышлений.
4. Нажми **Send to Claude** и наблюдай за статусами в панели. Сначала ИИ изучает музыку и пишет
   замысел (это видно только по статусам), потом игра сама открывает редактор и уровень появляется
   частями, затем бот проходит уровень.
5. Готовый уровень — в «Мои уровни». **Stop AI** — остановить в любой момент. **Undo AI** — откатить
   правки ИИ в редакторе.

Пока идёт стройка, не открывай этот уровень и не закрывай игру: игра нужна ИИ для стройки и проверки.
Переключаться на другие окна можно — игра не встаёт на паузу.

## Как это устроено

```
GD + мод claude.bridge  <-- TCP 127.0.0.1:47800 -->  tools/*.py  <--  Claude Code CLI (авторежим)
   окно заявки, панель,                              lvlkit/lvlpath — стройка «сначала путь»
   редактор, бот (sim_*)                             lvl_build — в редактор, lvl_check — бот + разбор
```

- `tools/start_claude.py` — запускает Claude Code по заявке с заданием `tools/auto_prompt.md`;
  разрешены только чтение/правка файлов проекта и запуск `python -P tools/...`.
- `tools/lvlkit.py`, `tools/lvlpath.py` — библиотека стройки: время ↔ x как в игре, порталы, блоки,
  карта музыки, путь игрока и точная физика, проверка столкновений.
- `tools/lvl_build.py` — ставит уровень в редактор; `tools/lvl_check.py` — бот и разбор.
- `tools/music.py`, `tools/music_map.py` — анализ любой песни (темп, удары, разделы).
- `docs/design_guide.md` — руководство по дизайну для ИИ; `.claude/skills/gd-builder` — навык для
  интерактивной работы в Claude Code.
- `mod/` — исходники мода (C++, Geode), `mod/SPEC.md` — протокол моста.

## Сборка мода из исходников (для разработчиков)

Нужны Geode SDK 5.11.2 (+ bindings для GD 2.2081), Visual Studio 2022 Build Tools (C++), CMake + Ninja.
Стандартная сборка Geode-мода:
```
cmake -S mod -B mod/build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build mod/build
```
`mod/build.ps1` — пример скрипта сборки с путями автора (поправь пути к VS и SDK под себя). Готовый
файл — `mod/build/claude.bridge.geode`.

## Ограничения и известные проблемы

- Сверена физика: куб, корабль, НЛО, волна (+мини), шар, паук, орбы, пады, порталы скорости и
  гравитации. Робот, swing, мини-куб/корабль/НЛО, дуал — пока не используются.
- Качество и разнообразие геймплея ещё дорабатываются.
- Не завершай игру принудительно (диспетчер задач) — Geode считает это падением и при следующем
  запуске предложит безопасный режим. Если при запуске игры держать Shift, Geode тоже предложит
  безопасный режим — отвечай «Нет».
- Мод слушает только 127.0.0.1 (локальный компьютер). В настройках есть **Read-only mode** — ИИ
  сможет только читать уровни и запускать бота.
- Песни в архив не входят — их скачивает сама игра.
